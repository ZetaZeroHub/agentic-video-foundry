# Deployment media

Tracked files in this directory are public, lightweight website assets.

`agentic-video-foundry-demo.mp4` is deliberately ignored by Git. Copy an approved public master to that exact path before packaging or deploying the site. Do not commit paid, private, or user media.

`og-cover.png` and `apple-touch-icon.png` are generated from the tracked SVG artwork and may be regenerated when the identity changes.
