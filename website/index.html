FAQ

What teams ask before installing

Direct answers about compatibility, rendering, credentials, and what “done” means in this workflow.

What is Agentic Video Foundry?

It is an open-source Agent Skill that coordinates briefing, storyboarding, real demos, narration, music, sound effects, subtitles, rendering, visual review, audio measurement, and editable delivery.

Which coding agents can use it?

It targets tools that follow the Agent Skills convention, including Codex, Claude Code, Gemini CLI, and compatible agent environments.

Which renderer owns the timeline?

Remotion is the default master compositor. Text-to-Lottie and HyperFrames are optional asset or scene routes, not competing master timelines.

Are API keys or paid media public?

No. Credentials stay in the OS keychain or environment variables. Paid and private media remains outside Git history and enters only separately approved deployment packages.
