# Agentic Video Foundry website

This directory contains the dependency-free public landing page for Agentic Video Foundry.

## Preview

Open `index.html` directly in a browser, or serve this directory with any static HTTP server.

## Publish

The site is compatible with GitHub Pages and other static hosts. Publishing is intentionally separate from building: validate the public copy, links, responsive layout, and repository state before enabling a deployment.

## Safety boundary

Do not add API keys, local absolute paths, paid assets, private recordings, or user media to this directory. The public case-study section contains text only until separately approved public assets are available.
