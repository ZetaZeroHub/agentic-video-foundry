FAQ

安装前最常问的四件事

直接说明兼容性、渲染路线、凭据边界，以及这套工作流对“完成”的定义。

Agentic Video Foundry 是什么？

它是开源 Agent Skill，负责协调任务诊断、分镜、真实演示、配音、音乐、音效、字幕、渲染、视觉复核、声音测量与可编辑交付。

哪些 coding agents 可以使用？

当前目标环境包括 Codex、Claude Code、Trae、Gemini CLI、Kimi Code、MiniMax，以及其他可加载 Agent Skills 或仓库指令的工具。

哪个渲染器负责主时间轴？

Remotion 默认负责唯一主合成。Text-to-Lottie 和 HyperFrames 是可选资产或场景路线，不会制造互相竞争的主时间轴。

API 密钥和付费媒体会公开吗？

不会。凭据保存在系统钥匙串或环境变量中；付费和私有媒体不进入 Git 历史，只在批准后进入单独部署包。
